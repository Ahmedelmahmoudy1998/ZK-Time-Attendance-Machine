# Desktop source snapshot — 28 September 2026

This repository contains the Oasis Attend source from the desktop “ChatGpt and claude” folder. Application source, tests, build scripts, icons, and logos were copied without modification. The supplied license, documentation, and third-party sources accompany them.

The desktop source includes updates beyond the previously packaged 1.1.0 installer. Existing README and VALIDATION notes describe that older packaged release and are not a validation report for this snapshot. This upload does not create a new installer or change the application's version.

Python files passed syntax parsing, and copied source files were verified against the desktop originals. No claim of full functional or hardware testing is made for this upload.

Attendance databases, login credentials, local settings, backups, exports, compiled applications, Python caches, internal conversation/planning notes, and the nested source ZIP are excluded. The two archives under `third-party-sources` are dependency source distributions, not attendance data.
